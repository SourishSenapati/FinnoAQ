## 1. Evidence Classifications

Every measurement, input, and derived variable recorded in the system must be tagged with one of the following immutable evidence classifications:

| Classification | Meaning & Data Integrity Rule |
| :--- | :--- |
| `observed_raw` | Unmodified measurement directly extracted from a certified laboratory instrument or technician report. |
| `derived_from_observed` | Mathematically transformed or aggregated variable calculated directly from `observed_raw` records. |
| `published_literature` | Published peer-reviewed literature finding, standard constant, or academic dataset. |
| `client_specification` | Formal commercial requirement or target provided by FinnoaQ stakeholders. |
| `assumption` | Explicit engineering assumption used when empirical data are missing (must include uncertainty range). |
| `hypothesis` | Candidate explanation or scientific proposition subject to experimental discrimination. |
| `simulation` | Output generated by mechanistic mathematical models, numerical PDE solvers, or virtual optimization. |
| `synthetic_test_only` | Isolated testing fixture used solely for software pipeline verification; **strictly forbidden** from real analysis. |
| `missing` | Scoped parameter for which no laboratory observation or reliable source is yet available. |
| `unverified` | Data received without cryptographic hash verification, calibration records, or chain of custody. |
