# Ingest New Laboratory Data

Inspect new supplied laboratory files without altering them. Hash inputs, preview sheets/pages/rows, map units and methods to the typed schema, preserve source-cell/row provenance, quarantine ambiguous rows, and distinguish observed data from derived/literature/synthetic values. Import validated rows transactionally into a new versioned normalized dataset, run schema/QC and leakage tests, and recompute only downstream dependencies. Do not impute missing measurements or count technical replicates as independent lots.
