PHASE 2 EXPERIMENT DESIGN PROMPT — DO NOT EXECUTE PHYSICAL EXPERIMENTS

Using only the validated Phase 1 outputs and the agreed scope, develop a preliminary, cost-aware experimental design for Phase 2. This task prepares a proposal; it does not authorize physical lab work, procurement, payments, external communications, commercial optimization or pilot processing.

1. Read the Phase 1 raw/normalized data manifest, QC report, statistical analysis, root-cause claim ledger and Phase 1 scope limitations.
2. Identify the few competing mechanisms that remain both plausible and decision-relevant. For each, provide supporting data, contradicting evidence, missing measurements and a falsifiable prediction.
3. Define candidate assays/treatments, factors/levels, experimental unit, replication, controls, blocking/randomization, endpoint(s), safety/quality/regulatory checks and a feasible cost/time envelope. Label assumed values and validate external cost/accreditation information if web research is permitted.
4. Specify priors and their sources, likelihood/model assumptions, expected-information-gain or decision-utility criterion, and constraints before calculating a Bayesian design. Assess sensitivity to priors and compare with a simple baseline design.
5. Recommend a sequence that separates diagnostic mechanism testing from optimization. Do not set an unsubstantiated “three tests are enough” target. Include criteria to stop, expand sample size, or abandon a mechanism.
6. Do not claim an experiment is optimal if inputs are missing or computations were not run. If required empirical data/priors/costs are absent, label the result `PRELIMINARY_NOT_OPTIMIZED` and list the exact inputs required.
7. Report expected information and uncertainty as model-based projections—not observations. Clearly state that all physical work requires separate client/lab authorization and agreed protocols.
